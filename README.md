# ai-usage-pace

AI 서비스의 사용량과 갱신 주기를 함께 보여 주어, 남은 할당량을 적절한 속도로 사용할 수 있도록 돕는 macOS 앱입니다.

## 초기 MVP 범위

- 사용량 한도와 갱신 주기 설정
- 현재 사용량 기록 또는 입력
- 주기 경과율과 사용량 소진율 비교
- 남은 기간과 권장 사용 속도를 한눈에 확인할 수 있는 요약 화면
- 설정과 사용량 데이터의 로컬 저장

초기 MVP에서는 계정 연동, 결제, 팀 단위 관리, 서버 동기화, 모바일 앱을 다루지 않습니다.

## 현재 상태

초기 저장소 설정 단계입니다. 아직 소스 코드와 Xcode 프로젝트는 포함되어 있지 않습니다.

## 개발 환경

- Swift
- Xcode
- macOS
